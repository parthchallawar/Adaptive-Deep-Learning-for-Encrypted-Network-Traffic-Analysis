## Problem

Spec 000 lists "a report/paper with ablations and multi-seed statistics" as a goal, but no spec says what that artefact must contain, where its numbers come from, or which experiments it still needs. Without that, the last phase is improvised and numbers get copied by hand.

## Goals

- A final-year report, a paper draft and a presentation whose every number is generated by `scripts/make_tables.py` or `scripts/benchmark.py` from tracked runs.
- The experiments a reader would ask for, listed and either run or explicitly marked untested.
- A fixed set of figures and tables, each with one generating command.

## Non-goals

- Submitting to a specific venue (decided by the owner later).
- New methods. This spec adds no model, policy or metric.

## Requirements

1. **Single source of numbers.** `results/summaries/*_table.{md,tex}` and `efficiency.md`. Prose numbers are checked against them in a final pass.
2. **Seeds.** Every row of the main table has three seeds, reported as mean ± std. One-seed results are allowed only in ablation tables and are labelled.
3. **Statistics.** Differences between two models on the same flows use the paired bootstrap already in `evaluation/bootstrap.py`, per seed.
4. **Honesty rules.** Failed hypotheses are reported as failed. Validation numbers are not results. Baselines that are re-implementations on our backbone are called that. No claim about detecting fraud, malware or attacks.
5. **Owed experiments.** The list in `plans/phase-7-report-paper.md` Part A; each ends as "run" or "not run, because".
6. **Reproducibility appendix.** Commit hash, config hash, Kaggle kernel version and hardware for every run in the main table.

## Success criteria

- Every figure and table regenerates from one documented command on a clean checkout with the results directory present.
- The limitations section names every failed or untested acceptance criterion from specs 007–013.

## Open questions

- Target venue and page limit: owner's decision; the report is written first and the paper is cut from it.
